# 小传说 · The Little Legend 5.0.0

5.0.0 修正格斗家空手得分与魔剑目标范围，牌桌弹窗不再阻断聊天、记录和顶部工具。提供 Windows / Android 主机与中文、English、日本語三种显示语言。旧版本与既有存档保留。本轮验证范围见 [5.0.0 验证记录](docs/VALIDATION-5.0.0.md)。

面向朋友局域网游玩的桌游电子化项目。只需 Windows 或 Android 主机安装软件，其他玩家使用浏览器加入；服务端统一处理卡牌效果、应对、回合和存档。支持 2–5 人。

## 使用发行包

- **Windows**：完整解压 `windows`，运行 `LittleLegendHost.exe`。保留相邻的 `app` 与 `runtime`，不能只复制 EXE。
- **Android**：安装 `android/LittleLegendHost-debug.apk`。最低 Android 8，目前仅 arm64；这是调试签名包，升级须保持同一签名。主要面向横屏。
- 启动面板端口留空自动分配，也可手填固定空闲端口。把显示的局域网地址发给同网络的朋友。
- 主机须保持运行；房间转交房主只是权限交接，不会搬迁服务器。穿透使用面板显示的本地端口，自行配置樱花穿透等工具。
- 首次登录注册账户，创建 / 加入房间。非房主准备后由房主开始。页顶字号旁可查玩法和卡牌图鉴。

## 功能

- 37 种卡牌、自动效果和触发应对、掷骰选座、顺时针回合、两人酒馆。
- 人数预设、替换角色双选、EX 逐牌启用、最终数量覆盖，改设置重新准备。
- 私有手牌、公共场上牌、宣言广播、详细日志、效果提示、聊天和弃牌区。
- 暂离返回、认输后观战、顺时针房主交接、暂停与申请审批。
- 服务端账户、头像、名片、动态词条、有效 / 中止统计及有效对局胜率。
- 每人最近五局全知回放，步进、拖动和自动播放；本机实时全知观战。
- Windows / Android 控制台、在线统计、空闲端口、统一图标、主题开场与登录。
- 字号 12–22、响应式牌桌；规则 / 图鉴浮窗可搜索筛选、拖动、缩放、置顶。
- WebSocket 实时同步，断线退回 HTTP 同步并自动重连；局部更新牌桌，保留未变动图片。
- 卡牌移动、手牌整理及攻击反馈，遵循系统减少动态效果设置；暗牌移动不展示身份。
- 一致同意回退上一步、选牌预览后确认、持续牌详情内独立发动、图鉴等级筛选。
- 5 首场景 BGM、24 个基础音效；字号旁分别控制音效与音乐的开关 / 音量，记住本设备偏好。登录页右上角同样可调声音。
- appbar 全部元素使用固定尺寸，调整游戏字号时顶部不缩放；小屏保留紧凑按钮。
- “介绍”浮窗包含玩法介绍与平台介绍，支持拖动、缩放、置顶；同名选牌会标明手牌、场上、牌库或弃牌堆等来源。
- 顶栏与登录页支持中文、英语、日语切换，记住本浏览器选择；Windows / Android 控制台亦可选语言。37 张卡的名称、效果、规则与平台介绍有英文 / 日文文本；图鉴支持译名搜索。原卡面图片、昵称、聊天与存档原文保留。
- 回放入口显示“请稍等…”并锁定两个列表，防止重复请求；失败可重试，过期会话不会进入错误的回放。
- 新设备默认 BGM 100、音效 70，保留既有偏好；音乐与音效共用一个 Web Audio 上下文，避免多个媒体播放器争抢输出。
- 优先预加载音乐、卡牌和其他素材，HTTP 缓存有效期 30 天；登录不续期。顶栏“本地资源”可手动重新获取，每账号北京时间每天一次，管理员可临时授予当日额外一次，未完成可续传。

## 从源码运行

推荐 **Node.js 24**。按锁文件安装纯 JavaScript WebSocket 依赖：

```powershell
npm ci --omit=optional --ignore-scripts
node host/prepare-audio.js
node host/prepare-languages.js
npm test
npm start
```

打开输出地址。默认使用系统分配的空闲端口。指定端口与数据目录：

```powershell
$env:PORT = '8080'
$env:XCS_DATA_DIR = 'D:\LittleLegendData'
npm start
```

不要同时让新旧服务写同一数据目录。4173 / 4174 不是固定依赖。

## 数据与管理

源码默认 `data/`；Windows 为 `%LOCALAPPDATA%\LittleLegend\data`；Android 为应用私有 `files/data`。首次启动创建数据，不附带现成账户。

控制台可打开本机管理，密钥是数据目录的 `admin.key`。密码仅存不可逆哈希；忘记密码由管理员核实身份后重置。停服后整体备份数据目录，Android 卸载会清除私有数据。

注销可恢复，永久删除清除账户凭据与资料；仍有其他参与账户的共享回放保留。最后一人离开解散房间并释放号码，全员离开未完成对局计中止。详见 [数据管理](host/data-management.md)。
