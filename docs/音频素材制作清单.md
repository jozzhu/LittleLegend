# 小传说音频素材制作清单

版本：2026-11-01。本文是制作需求，尚未接入音频播放。文件名作为后续接入约定，时长允许围绕建议值调整。

## 整体听感

主题是皇室与魔物围坐木桌，争夺金币的小型奇幻桌游。希望有精致桌面游戏的实物感，以及轻巧、略带戏剧性的奇幻气氛。紧张但不恐怖，热闹但不喧闹。

- 皇室音色：短弦、竖琴、轻钟、少量柔和铜管，明亮而克制。
- 魔物音色：低音拨弦、木质打击、气息与短促低音，狡黠而非惊悚。
- 桌面质感：纸牌、木头、金属金币、骰子，应当近、干净、有分量。
- 高频不要刺耳，低频不要轰鸣；不用持续的人声、歌词、战斗呐喊。
- 保持原创。可以参考优秀卡牌游戏“动作清楚、有层次”的思路，不复制现成旋律、标志音色或素材。

## 第一批 BGM

前三首优先制作。对局音乐使用同一首混合皇室与魔物动机，避免每次换玩家就换曲。

| 优先级 | 文件名 | 场景与建议长度 | 制作方向 |
| --- | --- | --- | --- |
| 必需 | `bgm_lobby` | 登录、准备房间；90–120 秒；无缝循环 | 温暖木桌、轻拨弦与竖琴，偶有魔物低音回应，有期待感但不催促 |
| 必需 | `bgm_match` | 常规对局；120–180 秒；无缝循环 | 中低强度律动，弦乐拨奏、木质打击、少量钟声；给思考和提示音留空间 |
| 必需 | `bgm_tension` | 接近胜负时；60–90 秒；无缝循环 | 与对局曲同一音乐动机，略紧凑，不突然变成激烈战斗；可与常规曲平滑衔接 |
| 可后补 | `bgm_replay` | 全知观战与回放；90–120 秒；无缝循环 | 对局曲的疏朗版本，弱打击，便于长时间观察 |

循环版不要淡入淡出，不要在循环点留静音；保留自然衔接。另附正常收尾的试听版可以，但请与循环版分开命名。开场和结算短乐句放在下方音效表，不要混入循环 BGM。

## 第一批基础音效

共 24 项。先做这一批即可覆盖主要游戏流程。同一项目可以额外提供两三个细微变化，例如 `sfx_card_draw_01`、`sfx_card_draw_02`，但不要为了变化显著改变响度。

| 序号 | 文件名 | 触发用途 | 建议时长 | 声音方向 |
| --- | --- | --- | --- | --- |
| 1 | `sfx_ui_click` | 常规按钮、确认操作 | 0.05–0.15 秒 | 极轻木质触点，清楚、不像机械鼠标 |
| 2 | `sfx_ui_panel` | 打开或关闭设置、图鉴、名片 | 0.15–0.3 秒 | 轻翻页或薄木滑动，不加大混响 |
| 3 | `sfx_ui_error` | 操作不合法、提交失败 | 0.2–0.4 秒 | 克制的两音提醒，避免刺耳警报 |
| 4 | `sfx_player_ready` | 玩家准备 | 0.2–0.5 秒 | 小木扣落位，加一粒轻钟 |
| 5 | `sfx_dice_roll` | 掷骰动画过程 | 0.8–1.2 秒 | 骰子在木桌上滚动，末尾渐停，不含报点 |
| 6 | `sfx_dice_result` | 点数落定、座位确认 | 0.2–0.5 秒 | 干脆落桌加小亮音，各点数共用 |
| 7 | `sfx_match_start` | 准备完成、正式开局 | 1.5–2.5 秒 | 短促奇幻开局乐句，有仪式感，收尾利落 |
| 8 | `sfx_turn_start` | 轮到自己行动 | 0.4–0.8 秒 | 易辨识的两三音提示，与普通点击明显区分 |
| 9 | `sfx_card_draw` | 从牌库抽牌 | 0.15–0.35 秒 | 单张纸牌抽离、轻滑；暗抽不区分角色或等级 |
| 10 | `sfx_card_play` | 主动打出卡牌 | 0.2–0.45 秒 | 纸牌落木桌，比抽牌更有重量，结尾干净 |
| 11 | `sfx_card_place` | 效果将牌放到场上 | 0.15–0.35 秒 | 轻落牌，弱于主动打出，区别“放置”与“发动” |
| 12 | `sfx_card_return` | 场上牌返回手牌、公开回收 | 0.2–0.45 秒 | 纸牌收拢与向上滑动，避免做成新的抽牌声 |
| 13 | `sfx_card_discard` | 弃牌进入弃牌区 | 0.2–0.45 秒 | 纸牌滑入薄牌堆，略带摩擦 |
| 14 | `sfx_coin_gain` | 获得金币 | 0.3–0.6 秒 | 一枚金属金币轻落木桌，短而清亮 |
| 15 | `sfx_coin_steal` | 从另一名玩家处抢走金币 | 0.4–0.8 秒 | 金币快速滑走再落下，区别普通获得金币 |
| 16 | `sfx_attack` | 攻击指定目标 | 0.3–0.65 秒 | 短掠风加轻冲击，适合卡牌，避免刀刀砍肉感 |
| 17 | `sfx_response_request` | 轮到自己选择应对 | 0.35–0.7 秒 | 小悬念的提示音，能与自己回合开始区分 |
| 18 | `sfx_defend_success` | 应对成功、抵消攻击 | 0.4–0.8 秒 | 清脆护盾碰撞，尾部轻亮，别压住后续抽牌 |
| 19 | `sfx_effect_fizzle` | 应对或牌效未满足条件 | 0.25–0.5 秒 | 轻微魔力消散，不像网络错误、不讽刺玩家 |
| 20 | `sfx_declaration` | 法师宣言、小丑女或女巫宣告 | 0.5–0.9 秒 | 魔法展开、短铃或纸封打开，表示“公开宣言” |
| 21 | `sfx_chat` | 收到其他玩家聊天 | 0.1–0.25 秒 | 极轻木珠或柔和提示，能单独关闭 |
| 22 | `sfx_pause` | 对局暂停或恢复 | 0.3–0.6 秒 | 简洁中性提示；恢复可复用变体，勿带胜负情绪 |
| 23 | `sfx_victory` | 自己获胜 | 3–5 秒 | 皇室与魔物共用的短胜利乐句，克制凯旋；含自然尾音 |
| 24 | `sfx_defeat` | 自己认输或落败 | 2.5–4 秒 | 轻遗憾的奇幻收尾，不嘲讽、不做悲壮葬礼 |

多张牌或多枚金币连续变化时，后续由程序限制重复与叠加。素材本身请保持单次动作干净，不要把“五张连续抽牌”或“十枚金币叮当”做成唯一版本。

## 第二批增强音效

这些能增加辨识度，但可以在第一批接入并实测之后再制作。

| 文件名 | 用途与建议时长 | 制作方向 |
| --- | --- | --- |
| `sfx_opening` | 已有开场动画；约 6.4 秒 | 由轻低音起，纸牌交汇，最终徽记出现时收束；另附无音乐的轻特效版 |
| `sfx_royal_magic` | 皇室法术 / 持续牌发动；0.4–0.9 秒 | 细钟、光亮拨弦、柔和魔法展开 |
| `sfx_monster_magic` | 魔物法术 / 持续牌发动；0.4–0.9 秒 | 短气息、低拨弦、略带颗粒的魔法感 |
| `sfx_sword` | 勇者、圣剑、魔剑类效果；0.3–0.7 秒 | 短金属掠风；轻快而非重型武器 |
| `sfx_flame` | 龙焰、火龙等效果；0.5–1 秒 | 一小股火焰喷吐，结束迅速，不做长燃烧 |
| `sfx_reveal` | 公开展示 / 私人查看卡牌；0.3–0.6 秒 | 翻牌加细微亮音；私人查看只在查看者端播放 |
| `sfx_retrieve` | 从酒馆或弃牌区取得公开牌；0.3–0.6 秒 | 从牌堆抽取再收起，可代替基础抽牌声 |
| `sfx_persistent_tap` | 横置持续牌发动；0.2–0.4 秒 | 牌面轻转、短扣响，适合重复使用 |
| `sfx_vote_request` | 收到回退或暂停申请；0.35–0.7 秒 | 中性邀请提示，不要像立即生效 |
| `sfx_undo_complete` | 回退经全体同意并完成；0.5–0.9 秒 | 纸牌回卷或轻倒放质感；不是播放所有动作的倒放 |
| `sfx_player_join` / `sfx_player_leave` | 进入、离开房间；0.3–0.6 秒 | 轻落座与轻收拾桌面，不用门铃 |
| `sfx_match_interrupted` | 对局中止；1–2 秒 | 中性收束，必须区别胜利与失败 |

暂不需要给 37 张牌分别配完整音效或角色配音。先用“实物动作 + 皇室 / 魔物 + 剑 / 火焰 / 魔法”组合，实际玩过再为少数关键牌补专属声音。

## 交付文件与目录

请保留制作工程和高质量母版。建议交付：

- 母版：WAV，48 kHz，24 bit；音效单声道或居中立体声，BGM 立体声。
- 网页预览 / 播放版：MP3，BGM 可用 192 kbps；短音效优先同时保留 WAV，由接入阶段统一转换和核验。
- 一段音效一个文件，开头不要多余空白；保留合理自然尾音，不要截断混响。
- 不要削波，不要在母版做过度限制；同类音效主观响度接近，关键提示不靠突然大声。
- 请附实际时长与循环点说明。BGM 无缝循环交付以 WAV 母版为准，压缩版接入时再检查循环衔接。
- 原创或获得允许再分发的授权；若使用外部采样，请附来源、许可与署名要求，便于后续开源整理。

```text
assets/audio/
  masters/
    bgm/                 WAV 母版
    sfx/                 WAV 母版
  bgm/
    bgm_lobby.mp3
    bgm_match.mp3
    bgm_tension.mp3
    bgm_replay.mp3        可后补
  sfx/
    sfx_ui_click.wav
    sfx_card_draw_01.wav
    ...
  AUDIO_CREDITS.md        作者、授权、采样来源
  audio-notes.md          实际时长、循环点、特殊说明
```

先把素材放在 `assets/audio/` 即可，不必自行复制到 `public/`，后续接入时统一处理。制作工程和大体积母版先本地保留，公开源码是否收录再单独整理。

## 接入时的播放约定

这是后续实现约定，本次没有增加播放功能：

- 公开出牌、公开拿牌、攻击、应对结果等，桌上玩家都能听见；按事件去重，不因同步、断线重连或打开回放重复播放。
- “轮到你”和“请应对”只在需要操作的玩家端播放；所有攻击都遵循同样的询问流程，不能用提示差异泄露是否有应对牌。
- 暗抽共用音效，不按暗牌角色、等级或效果区分。私人看牌提示仅给查看者。
- 认输者仍在桌上观战，保留公开动作音效；败北短乐句仅首次认输或结算时播放，不能每次刷新重播。
- 音乐、游戏音效、聊天提示分别可调和静音；提供整体静音。首次进入先等待玩家主动开启声音。
- 断线恢复不补播一长串历史声音；回放默认不重复播放聊天提示和私人操作提醒。
- BGM 切换平滑淡入淡出，降低对提示音的干扰。接近胜负的切换只依据公开信息。
- 多人同时结算时限制叠音，金币多枚只做轻微重复；音乐与音效不要共同把声音堆满。
