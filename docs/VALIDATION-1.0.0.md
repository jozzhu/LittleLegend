# 1.0.0 验证记录

整理日期：2026-11-01。工具环境：Windows，Node.js 24.15.0，Android SDK 35 / NDK r27c / Gradle 8.9。

## 自动测试

`npm test` 共 134 项，覆盖规则、账户、隐私、HTTP 生命周期、返回房间、房主交接、认输、回放、中止统计、成就、删除及无关联数据清理、配置预设、开场协调、观战权限、客户端行为。

本次新增覆盖：

- 全部 37 种卡牌，组合搜索 / 阵营 / 效果 / EX 筛选。
- 详情查看与返回，规则与图鉴同时打开。
- 浮窗置顶、取消置顶、关闭与重开、拖动、缩放、旋转后的边界限制。
- 原生 modal 对话框打开时，浮窗移入活动对话框以保持可点击，关闭后回到页面。
- 两平台新观战入口，Android 使用 Sync 清理旧网页资源。

客户端交互通过 VM 中的 DOM 替身测试，**不能替代真实浏览器布局、鼠标与触摸验收**。
