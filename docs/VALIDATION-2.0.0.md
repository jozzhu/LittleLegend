# 2.0.0 验证记录

日期：2026-11-01。环境：Windows，Node.js 24.15.0，PowerShell 7，Android SDK 35 / NDK r27c / Gradle 8.9。

## 完整回归

最终开发代码 `npm test`：153 项通过，0 失败、0 跳过，约 5.6 秒。包含 40 局完整自动规则模拟。所有此前暂缓测试的改动均纳入本轮，不只测试 WebSocket。

- 龙幼崽由发动者选牌，酒馆与弃牌区公开拿牌，主动弃牌的行动点 / 手牌 / 响应限制。
- 回退一致同意、拒绝 / 撤销、认输观战者投票、跨回合恢复、统计冲回、旧提示密钥失效及隐私。
- 用户审核后的金币来源与抢夺统计、当前持有者回手、详细日志及公开牌名。
- 选牌先预览再确认、返回不提交、暗牌不显示身份、持续牌独立发动、暂停或提示过期时失效。
- 图鉴等级零 / 无等级与搜索等条件组合。
- 账户、登录恢复、房间返回 / 离开、房主移交、认输、回放、暂停、设置预设、统计与账户删除等既有回归。
- 同一端口五个 WebSocket 客户端，各自只能收到允许查看的牌面；同源 / 登录检查、登出关闭、断线重连与轻量 HTTP 响应。
- 五人并发命令不丢聊天；确认后文件已落盘。异步写入合并、失败上报与房间副本隔离。
- 客户端拒绝旧快照，未变化区域不重建，断线启用 HTTP 同步；超时释放操作锁后同步，不重发命令。
- 动效规划使用可见牌身份，暗抽使用牌背，回退不播放正向移动。

## 性能测量

自动测试在本机回环网络连接五个客户端，连续提交 12 次聊天命令。计时包括 HTTP 命令、持久化完成及五客户端收到推送，最终测得 p50 3.9 ms、p95 4.6 ms。样本少，仅用于局部回归；不等于真实 Wi-Fi、穿透、手机浏览器或复杂后期牌桌的帧率和延迟。

本次没有对旧版进行同环境完整基准，不能据此宣称性能提升的倍数。HTTP 通常复用连接，本轮重点减少轮询等待、完整状态传输、历史复制、同步文件写入及重复 DOM 更新。

Windows 2.0.0 包内运行时启动隔离数据服务，检查 37 张牌、实时依赖与静态页面，不使用真实数据。Android 2.0.0 / versionCode 20 为调试签名 arm64 包，核对签名、原生库、图标、内置服务端 / 网页及 `ws` 依赖与开发代码一致。

干净源码白名单导出，含锁文件、测试、完整构建说明与设计修复历程；排除账户、密钥、回放、SDK、缓存、签名和运行时二进制。导出源码再运行完整自动测试。发行包与源码 ZIP 附 SHA256 校验文件，旧 1.0.0 导出保持不变。
